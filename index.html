💡 How It Works & Note on Online Gaming

NetBond Dispatcher operates at Layer 7 (Socket & Application Level). Single-socket UDP game connections (like Valorant or Roblox) cannot split individual packets across two IPs without disconnection. However, NetBond allows you to leave your primary LAN adapter dedicated to low-ping gaming while routing browsers, downloads, and live streams through your secondary Wi-Fi adapter.

Core Capabilities

Engineered for simplicity, low resource usage, and clean socket binding.

⚡

Parallel Chunk Downloader

Splits large HTTP range requests into parallel chunks, assigning each stream to distinct physical adapters for accelerated combined speed.

🔄

Local SOCKS5 Dispatcher

Runs locally on 127.0.0.1:10808, intelligently balancing outbound browser or app connections across your active network interfaces via Round-Robin.

📊

Live Throughput Telemetry

Displays real-time per-adapter and aggregated upload/download speeds directly sampled from Windows network interface statistics.

🚀

Velopack Auto-Updates

Features silent background update checks straight from official GitHub Releases, keeping your setup up to date effortlessly.

How to Use

Simple guides to get your multi-adapter setup running in seconds.

A

Using the SOCKS5 Proxy (Browser / Streaming)

1. Open the app and ensure your adapters (e.g., Ethernet + Wi-Fi) show Up status in the Network Adapters tab.
2. Go to Dashboard or SOCKS5 Proxy and click Toggle SOCKS5 Proxy.
3. Configure your browser, download manager, or OBS proxy settings to:

Host: 127.0.0.1 | Port: 10808 (SOCKS5)
B

Using the Parallel Chunk Downloader

1. Switch to the Parallel Downloader tab.
2. Paste any direct download link that supports HTTP Range requests (e.g., .mp4, .zip, .bin).
3. Select your target save path and number of chunks, then click Start Download.

C

Background & System Tray Operation

Under Settings & Updates, enable Minimize to system tray when closing window and Start automatically with Windows for a seamless set-and-forget background service.
